# src/components/calendar/ — Editorial Calendar & Scheduling Components

This directory contains client components for the editorial calendar workbench, scheduled posts management, and manual dispatch.

## Structure
- `calendar-workspace.tsx` — Monthly calendar grid, month controls, day indicators, and the pinned "Today's Posts" sidebar.
- `day-fullscreen-modal.tsx` — Fullscreen deep-dive view into all scheduled and published posts for a specific day.
- `publish-post-modal.tsx` — Frictionless manual dispatch modal (1-click copy text, asset downloads, mark published) and 1-time Auto-Posting Trust Poll.

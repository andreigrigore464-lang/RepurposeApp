# Review & Editorial Workbench UI Components

This folder contains the client components powering the format review and editorial editing interface (`/review/[id]`).

## Files

- `format-workbench.tsx`: Master review workbench coordinating platform variant tabs, character limit counters, copy editor, and visual previews.
- `video-reel-player.tsx`: Dedicated 9:16 vertical video player for previewing cut video reels with MP4 download, WebVTT/SRT subtitle export, and schedule actions.
- `grounding-provenance-panel.tsx`: Grounding inspector listing exact source quotes and sentences verifying factual authenticity.
- `schedule-modal.tsx`: Interactive modal for scheduling ready formats directly to social publishing calendar slots.

# src/components/ — UI Presentation Components

This directory contains client and server components for the editorial workbench:

- `brand/` — Brand Kit color palette, typography selector, and voice guidelines preview.
- `feeds/` — Feed management, URL ingest inputs, and status badges.
- `inbox/` — Editorial drafts inbox table, filtering, format review pills, and delete actions.
- `landing/` — Public landing page, visual grounding comparison, and waitlist submission form.
- `nav-header.tsx` — Global editorial navigation bar.
- `review/` — Grounding provenance inspector and side-by-side editing canvas.

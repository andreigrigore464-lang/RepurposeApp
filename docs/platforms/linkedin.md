# Platform Constraints: LinkedIn

## 1. Platform Identity
- **Identifier:** `linkedin`
- **Supported Formats:** `text-post`, `card`, `carousel`
- **Native Delivery Method:** Manual copy/paste of text, download of PNG for cards, download of PDF document for carousels.

---

## 2. Technical Constraints

| Property | Limit / Rule | Notes |
|---|---|---|
| **Max Character Count** | 3,000 characters | Recommended target: 1,000–1,800 characters for optimal readability. |
| **Visible Truncation (The Fold)** | ~210 characters (3 lines) | Opening hook must capture attention before the "...see more" cutoff. |
| **Hashtags** | 3 to 5 tags | Placed cleanly at the bottom; camelCase format preferred (e.g., `#DigitalPublishing`). |
| **Images** | 1 image for `card` format | PNG, 1080x1080 (1:1) or 1200x627 (1.91:1). |
| **Document / Carousel** | Multi-page PDF | Native LinkedIn document post displays as swipeable presentation. Export as PDF. |
| **Links** | Allowed in post body | Editorial best practice: clean URL or "link in comments" note depending on brand preference. |

---

## 3. Formatting & Styling Rules
- Line breaks: Use double line breaks between short paragraphs for clean mobile formatting.
- Bullet points: Standard Unicode bullet points (`•`, `—`) are supported.
- Tone default: Professional, analytical, authoritative, grounded.

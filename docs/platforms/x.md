# Platform Constraints: X (Twitter)

## 1. Platform Identity
- **Identifier:** `x`
- **Supported Formats:** `text-post`, `thread`, `card`
- **Native Delivery Method:** Copy/paste of individual tweets / thread blocks, download of PNG for cards.

---

## 2. Technical Constraints

| Property | Limit / Rule | Notes |
|---|---|---|
| **Max Character Count (Standard)** | 280 characters per tweet | Hard ceiling for standard accounts. Target: 240–260 chars. |
| **Thread Structure** | 2 to 10 sequential posts | Sequential numbering format: `1/n`, `2/n` or `1/`, `2/`. |
| **Hashtags** | 0 to 2 maximum | High hashtag count harms reach on X. Placed inline or at end of thread. |
| **Images** | Max 4 per tweet (card format uses 1) | PNG, 1080x1080 (1:1) or 1200x675 (16:9). |
| **Carousel Support** | None natively | `carousel` format does NOT map directly to X; use `thread` instead. |
| **Links** | Consumes 23 characters | t.co auto-wrap reservation. |

---

## 3. Formatting & Styling Rules
- Brevity is paramount: eliminate fluff, passive voice, and conversational fillers.
- Hook post: Needs punchy statement or surprising data point without thread numbering taking up too much room.
- Thread concluding post: Clear CTA pointing to article link.

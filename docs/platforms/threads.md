# Platform Constraints: Threads

## 1. Platform Identity
- **Identifier:** `threads`
- **Supported Formats:** `text-post`, `thread`, `card`
- **Native Delivery Method:** Copy text blocks to clipboard, download PNG for graphic card.

---

## 2. Technical Constraints

| Property | Limit / Rule | Notes |
|---|---|---|
| **Max Character Count** | 500 characters per post | Concise microblogging limit. Target: 350–480 chars. |
| **Thread Structure** | 2 to 10 sequential posts | Thread segments split by 500 characters maximum. |
| **Hashtags / Topics** | 0 to 1 tagged topic | Threads uses single topic tags rather than multi-hashtag clouds. |
| **Images** | Up to 10 images per post | 1080x1080 (1:1) or 1080x1350 (4:5). |
| **Carousel Support** | Handled as multi-image post or thread | Supported via multi-image attachment or text thread. |
| **Links** | Clickable in post | Link previews expand automatically. |

---

## 3. Formatting & Styling Rules
- Conversational, sharp, intellectual tone.
- Avoid aggressive hashtag spamming and excessive emojis.
